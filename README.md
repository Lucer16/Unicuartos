# UniCuartos | Encuentra y Publica Habitaciones para Estudiantes

¡Bienvenido a **UniCuartos**!

Este proyecto consiste en una plataforma web diseñada para facilitar la búsqueda y publicación de habitaciones, cuartos, apartamentos y residencias dirigidas principalmente a estudiantes universitarios en Panamá. Su objetivo es conectar a propietarios con estudiantes que buscan un lugar seguro, cómodo y cercano a su universidad.

La aplicación fue desarrollada utilizando **HTML, CSS, Tailwind CSS y JavaScript**, ofreciendo una interfaz moderna, intuitiva y completamente responsiva para brindar una excelente experiencia de usuario desde cualquier dispositivo.

## 🚀 Objetivo del Proyecto

Este proyecto tiene como finalidad:

- Facilitar la búsqueda de habitaciones y apartamentos para estudiantes universitarios.
- Permitir a propietarios publicar anuncios de manera sencilla.
- Centralizar la oferta de alquileres cercanos a las universidades.
- Reducir el tiempo de búsqueda de alojamiento para estudiantes.
- Ofrecer una plataforma gratuita y fácil de utilizar.
- Aplicar buenas prácticas de desarrollo Frontend mediante una interfaz moderna y optimizada.

## ✨ Características

- 🏠 Publicación de habitaciones y apartamentos.
- 🔍 Búsqueda rápida de anuncios.
